## ⚡ Tech Stack

- **Framework**: [Next.js 16](https://nextjs.org/) (App Router, Turbopack, SSG prerendering)
- **UI Library**: [React 19](https://react.dev/)
- **Language**: [TypeScript](https://www.typescriptlang.org/) (Strict mode)
- **Styling**: [Tailwind CSS v4](https://tailwindcss.com/) & custom CSS design tokens
- **3D Graphics & Visuals**: [Three.js](https://threejs.org/) (WebGL interactive orbital constellation & ambient canvas backdrop)
- **Typography**: [DM Sans](https://fonts.google.com/specimen/DM+Sans), [Instrument Serif](https://fonts.google.com/specimen/Instrument+Serif), and [JetBrains Mono](https://fonts.google.com/specimen/JetBrains+Mono)
- **Icons**: [Lucide React](https://lucide.dev/)
- **SEO & Structured Data**: JSON-LD (`Person`, `WebSite`, `ProfilePage`, `SoftwareApplication`), dynamic OpenGraph cards (`next/og`), `sitemap.xml`, and `robots.txt`

## 🛠️ Getting Started

### Prerequisites

- [Node.js](https://nodejs.org/) (v18.18 or higher recommended)
- `npm`, `pnpm`, or `yarn`

### Installation

```bash
git clone https://github.com/DevYuvi/newPortfolio.git
cd newPortfolio
npm install
```

### Running Locally

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

### Quality & Build Verification

```bash
# Type check with TypeScript
npm run typecheck

# Lint check with ESLint
npm run lint

# Production build
npm run build
```
